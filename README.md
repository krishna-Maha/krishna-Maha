# Load Test Project

A GitHub-based load testing project with automated workflows and comprehensive test infrastructure.

## Project Structure

```
.
├── .github/workflows/      # GitHub Actions workflows
├── load-tests/             # Load test scripts
├── scripts/                # Utility and helper scripts
├── test-data/              # Test data files and fixtures
├── results/                # Raw test results
├── reports/                # Generated test reports
├── docs/                   # Documentation
├── config/                 # Configuration files
├── env/                    # Environment configuration
└── README.md               # This file
```

## Getting Started

This is the initial scaffold for the load test project. Add your:
- Load test scripts to `load-tests/`
- Supporting scripts to `scripts/`
- Test data to `test-data/`
- GitHub Actions workflows to `.github/workflows/`
- Configuration to `config/` and `env/`

See `docs/` for detailed setup and usage instructions.
